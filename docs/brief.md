Buat sebuah **personal portfolio website yang fun, playful, dan memiliki aesthetic pixel-art seperti game RPG/arcade klasik**, tetapi tetap terlihat modern, profesional, dan nyaman digunakan.

## Konsep Utama

Website ini bukan sekadar portfolio biasa. Buat pengalaman seperti pengunjung sedang memasuki sebuah **mini pixel-art game world** yang merepresentasikan seorang software developer.

Tema:

* Pixel game
* Retro RPG
* Arcade
* Developer / coding
* Playful
* Nostalgic tetapi modern
* Fun dan sedikit quirky

Gunakan konsep **"My Developer Adventure"** atau **"Welcome to My World"**.

## Visual Style

Gunakan:

* Pixel-art aesthetic
* Pixelated UI
* Retro game interface
* 8-bit / 16-bit inspiration
* Pixel borders
* Pixel icons
* Small sprite characters
* Retro dialog boxes
* Game HUD
* Retro buttons
* Subtle CRT / scanline effect
* Pixel particles
* Floating game objects

Namun jangan membuat website terlihat seperti game jadul yang sulit digunakan. Typography dan spacing tetap modern agar usability tetap bagus.

Gunakan kombinasi:

* dark navy / deep purple background
* warm accent colors
* neon cyan
* purple
* yellow
* green
* soft white

Jangan menggunakan terlalu banyak warna secara bersamaan. Buat color palette yang konsisten.

## Hero Section

Hero section harus langsung memberikan kesan seperti memasuki sebuah game.

Contoh:

"PRESS START"

kemudian muncul:

"Hi, I'm [NAME]"
"Fullstack Developer"

Subtitle:

"I build things, break things, and somehow make them work."

Buat karakter pixel-art kecil sebagai avatar developer.

Tambahkan tombol:

[ START ADVENTURE ]
[ VIEW PROJECTS ]

Buat tombol terasa seperti tombol pada game console.

Hero background dapat berupa:

* pixel city
* developer room
* computer desk
* small pixel world
* nighttime environment

Tambahkan animasi kecil seperti:

* blinking cursor
* floating pixels
* character idle animation
* glowing monitor
* moving clouds
* particles

## Responsiveness

Website harus responsive untuk:

Laptop
Tablet

Game UI harus tetap nyaman digunakan pada touchscreen.

## UX

Walaupun menggunakan tema game, website harus tetap:

* mudah dinavigasi
* cepat
* readable
* accessible
* responsive
* SEO friendly
* tidak terlalu ramai
* tetap terlihat profesional sebagai portfolio developer

Jangan membuat semua elemen bergerak terus menerus.

## Important Design Principle

Website harus terasa seperti:

"Seorang developer membuat portfolio dalam bentuk sebuah game."

Bukan:

"Website biasa yang ditempeli gambar pixel."

Pastikan seluruh UI, copywriting, interaction, navigation, section naming, dan animation terasa memiliki **game identity yang konsisten**.

Overall feeling:

🎮 Fun
🕹️ Retro
👾 Nerdy
💻 Developer-focused
✨ Playful
🚀 Modern
🔥 Memorable

Hasil akhirnya harus membuat pengunjung merasa:

"Ini portfolio developer, tapi rasanya seperti sedang memainkan game."
